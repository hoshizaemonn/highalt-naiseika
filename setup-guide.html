High Altitude Management様 ／ 安蒜様向け

GitHub ＋ Claude Code 導入手順書（無料ではじめる版）

2026-08-03 ／ パソコンの専門知識ゼロを前提に、Windows・Mac 両方の手順を書いています。
所要時間の目安：合計75分（1日で終わらせず、STEPごとに区切って進めて大丈夫です）

★はじめに ─ この手順書で何ができるようになるか

  1. AIに「資料を作って」と日本語で頼むと、そのまま見られる資料ができる。弊社が御社にお出ししている図解資料も、この環境で作っています。
  2. 作った資料が自動で保存され、URLで人に見せられる。ファイルを添付して送る必要がなくなります。
  3. 費用は0円で始められます。ただし後述の通り無料には明確な制限がありますので、そこは正直にお伝えします。

全体像 ─ 4つの部品を順番に入れるだけです

STEP 1

GitHub

作った資料を保管して、URLで見せられるようにする「倉庫」。無料。

STEP 2

Node.js

次の道具を動かすための土台。1回入れたら以後さわりません。無料。

STEP 3・5

Claude Code

AIに日本語で頼むと、資料やファイルを実際に作ってくれる道具。

STEP 4

OpenRouter

AIの「頭脳」を無料で借りる先。カード登録なしで使えます。

この手順の位置づけ：本来 Claude Code は Claude（月3,000円台）を頭脳として動かす道具です。この手順書では費用0円を優先し、頭脳の部分だけ無料のAI（NVIDIA Nemotron等）に差し替えて使います。そのため答えの質はClaude本体より落ちます。まず0円で体験し、物足りなければSTEP 7で正規版に切り替える、という流れをおすすめします。

【重要】「黒い画面」の開き方 ─ この先、何度も出てきます。分からなくなったらここに戻ってください

手順書に「黒い画面で」と書いてあったら、毎回この操作で開きます。一度閉じてしまっても、また同じ手順で開けば大丈夫です。

Windows の場合
  1. 画面下のタスクバーの 🔍 検索 ボックスをクリック
    （無ければ Windowsキー を押す）
  2. cmd と入力（半角英字3文字）
  3. 出てきた 「コマンド プロンプト」 をクリック

黒い画面が開けば成功です。C:\Users\...> の右でカーソルが点滅しているので、そこに文字を打ちます。

「PowerShell」ではなく「コマンド プロンプト」を使ってください。PowerShellだと、Windowsの安全装置に弾かれてスクリプトの実行が無効になっているため…という赤いエラーが出ます（STEP 2の管理者操作だけは例外でPowerShellを使います）。
Mac の場合
  1. command + スペース を同時に押す
  2. ターミナル と入力
  3. Enter を押す

白か黒の画面が開けば成功です。カーソルが点滅しているところに文字を打ちます。

「管理者として実行」が要るのはSTEP 2だけです。STEP 3以降は、普通にクリックして開くだけで構いません。
打ち方のコツ：コマンドはコピーして貼り付けで構いません。貼り付けは Windows なら Ctrl+V、Mac なら command+V。打ち込んだあとは必ず Enter を押してください。

先に知っておいてください ─ 無料ルートの3つの制限

  • 1日50回まで。無料枠は1日50リクエスト・1分20リクエストが上限です（OpenRouterに一度$10課金すると1日1000回に緩和されます）。資料を2〜3本作ると到達することがあります。
  • 答えの質はClaude本体より落ちます。頭脳が別のAIに変わるためです。「AIで資料が作れるか試す」目的には十分ですが、本番の提案書を任せきるには物足りない可能性があります。
  • 会社の機密情報・会員様の個人情報は入力しないでください。無料サービスは入力内容をAIの学習に使う場合があります。氏名・メール・住所・売上明細などは、この環境では扱わないでください。
迷ったら：まず無料で「AIで資料が作れる感覚」をつかむ → 実務で使うと決めたら Claude Pro（月3,000円台）に切り替える。この順番が安全かつ確実です。切り替え方はSTEP 7に書いています。
1
GitHub に登録する
約10分
ゴール：github.com にログインできる状態になる。作った資料の保管庫です。
  1. ブラウザで github.com を開く
  2. 右上の 「Sign up」（サインアップ）をクリック
  3. メールアドレス → パスワード → ユーザー名（半角英数字。例：anbiru-ha）を順に入力
    • ユーザー名は後からURLに出ます。会社名やお名前のローマ字が無難です
  4. 入力したメールアドレスに届く認証コードを入力
  5. 「What do you want to do?」等のアンケートはすべてスキップして構いません
  6. プラン選択は Free（無料） を選ぶ
✔ 確認：ログインした状態で github.com を開き、右上に自分のアイコンが出ていればOKです。
2
Node.js を入れる（土台づくり）
約15分
ゴール：黒い画面（ターミナル）で node -v と打つと v22 以上と表示される。
※ Node.js 自体を使うわけではありません。次の道具を動かすための土台です。1回入れたら以後さわりません。
Windows の場合
① 黒い画面を開く
キーボードの Windowsキー を押して powershell と入力 → 「Windows PowerShell」を右クリック → 「管理者として実行」

② 下記を貼り付けて Enter 
winget install OpenJS.NodeJS.LTS
途中で規約への同意を聞かれたら Y を入力して Enter。

③ 画面をいったん閉じて、開き直す（重要。閉じないと次の確認が失敗します）
Mac の場合
① 黒い画面を開く
command + スペース を押して ターミナル と入力 → Enter

② Homebrew（導入用の道具）を入れる 
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
途中でMacのパスワードを聞かれます。打っても画面に何も表示されませんが、入力はされています。そのまま打って Enter。

③ Node.js を入れる 
brew install node
④ 入ったか確認する（Windows・Mac共通） 
node -v
✔ 確認：v22.x.x のように22以上の数字が出ればOKです。
数字が20以下だった場合：この道具は Node.js 22以上が必要です。Windowsは winget upgrade OpenJS.NodeJS.LTS、Macは brew upgrade node を実行してから、もう一度 node -v で確認してください。
3
Claude Code と接続ツールを入れる
約5分
ゴール：2つの道具がパソコンに入る。
STEP 2の黒い画面をそのまま使います。閉じてしまった場合は ▶ 黒い画面の開き方はこちら
下記を1行ずつ貼り付けて Enter（Windows・Mac共通） 
# ① AIに作業させる道具（本体）
npm install -g @anthropic-ai/claude-code

# ② 無料のAIに繋ぎ替えるための道具
npm install -g @musistudio/claude-code-router
  • それぞれ1〜3分かかります。文字がたくさん流れますが、正常です
  • Macで permission denied と出たら、行の先頭に sudo を付けて再実行し、Macのパスワードを入力してください
✔ 確認：ccr -h と打って、Usage: で始まる説明が出ればOKです。
4
OpenRouter に登録して「鍵」を取る
約10分
ゴール：sk-or-v1- で始まる長い文字列（APIキー＝鍵）を手元にコピーできている状態。
※ 無料のAIを借りるための窓口です。クレジットカード登録は不要です。
  1. ブラウザで openrouter.ai を開く
  2. 右上の 「Sign in」 をクリック
  3. 出てきた窓の上部に、アイコンが3つ横並びで出ます。一番左（黒い猫のようなマーク＝GitHub）をクリック
    • 左＝GitHub（これを押します）／中央＝Google（4色のG）／右＝MetaMask（オレンジのキツネ・使いません）
    • 「Continue with GitHub」という文字のボタンはありません。アイコンだけです
    • STEP 1で作ったGitHubアカウントでログインでき、OpenRouterのアカウントも同時に作られます
  4. ログイン後、右上のアイコン → 「Keys」 をクリック
  5. 「Create Key」 をクリック → 名前は claude-code など何でも構いません → 作成
  6. 表示された文字列をコピーして、メモ帳などに貼って保存
    • この画面を閉じると二度と表示されません。必ず先に控えてください
    • この鍵はパスワードと同じです。人に見せない・チャットに貼らないでください
✔ 確認：メモ帳に sk-or-v1-xxxxxxxx... という長い文字列が保存されていればOKです。
「Invalid credentials」と赤字で出た場合：メールアドレスを入力して Continue を押すと、この表示になります。まだOpenRouterのアカウントが無いためで、故障ではありません。メール欄は使わず、窓の上部にある一番左のGitHubアイコンを押してください。それだけで登録とログインが同時に完了します。
5
無料のAIに繋ぎ替える（設定画面で操作）
約15分
ゴール：ブラウザの設定画面で、STEP 4の鍵を登録して接続が完了する。
ここはマウス操作の画面なので、黒い画面より簡単です。
① 設定画面を開く

▶ 黒い画面の開き方はこちら　で黒い画面を開き、下記を打ち込んで Enter。
※ STEP 2で開いた画面を閉じてしまっていても大丈夫です。開き直してください。

ccr ui

ブラウザが自動で開きます（開かない場合は http://127.0.0.1:3458 を手で開いてください）。

この黒い画面は、作業が終わるまで閉じないでください。× で閉じたり Ctrl+C を押すと接続が切れ、サービス開始に失敗しました／コアゲートウェイは3221225786で終了しました というエラーになります。最小化はしても大丈夫です。閉じてしまった場合は、もう一度 ccr ui から実行してください。
② AIの提供元を登録する
  1. 左メニューの Providers → Add Provider
  2. OpenRouter を選ぶ
  3. API Key の欄に、STEP 4でコピーした鍵を貼り付け
  4. モデルを追加する。一覧が「0件／提供者モデルなし」でも正常です。右側の 「＋ カスタムモデル」 をクリックし、下記をそのまま貼り付けてください
    nvidia/nemotron-3-ultra-550b-a55b:free
    • 追加したら、中央の 「>」ボタンで右側の「追加モデル」へ移します
    • うまくいかない時の予備：cohere/north-mini-code:free ／ openai/gpt-oss-20b:free
    • 末尾の :free が無料の目印です。これが付いていないものを選ぶと課金されます
  5. 保存
③ 接続する
  1. Agent Config を開く
  2. エージェント一覧から Claude Code を選ぶ
  3. デフォルトモデルに、②で追加したモデルを選んで 適用（Apply）
    • OPUS／ソネット／俳句モデルなどの欄は「Claude Codeはデフォルトに保つ」のままでOKです
    • 赤字でデフォルトモデルが必要ですと出る時は、この欄が未選択です
  4. このプロファイル名をメモしてください（次のSTEPで使います）
  5. Server を開いて Start をクリック
✔ 確認：Server の表示が「起動中（Running）」になっていればOKです。
ネット上の古い情報にご注意：「ccr code と打つ」と書いてある記事が多くありますが、それは旧バージョンの書き方で、現在（v3系）では動きません。上記の設定画面から進めてください。
6
実際に資料を1本つくってみる
約20分
ゴール：AIに日本語で頼んで、資料のHTMLファイルが1つできる。ここまで来れば導入完了です。
① 作業用のフォルダを作って、その中で起動する

▶ 黒い画面の開き方はこちら　で開いた画面に、下記を1行ずつ打ち込んで Enter。

# デスクトップに shiryo という作業フォルダを作る
cd Desktop
mkdir shiryo
cd shiryo

# STEP 5でメモしたプロファイル名で起動（例：default）
ccr default

起動すると、画面下に文字を打ち込める状態になります。ここがAIとの会話欄です。

② 日本語でそのまま頼む 
会社の月次report用のHTMLを1枚作ってください。
内容は「今月の売上・課題・来月の打ち手」の3セクション。
数字は仮でOK。スマホでも崩れないようにしてください。
  • ファイルを作ってよいか聞かれたら Yes を選んでください（矢印キーで選んで Enter）
  • できあがったファイルは、デスクトップの shiryo フォルダに入ります
  • ダブルクリックで開けば、そのままブラウザで資料が見られます
③ 直したいところを日本語で伝える 
売上のセクションに棒グラフを足してください。
文字が小さいのでもう少し大きく。
✔ 確認：フォルダの中にHTMLファイルができ、ブラウザで開けたら導入完了です。おつかれさまでした。
GitHubに保存して人に見せたくなったら：会話欄に「このフォルダをGitHubに保存して、URLで見られるようにして」と日本語で頼めば、AIが手順を案内しながら進めてくれます。最初の1回だけログイン操作が入ります。
7
物足りなくなったら正規版に切り替える
約5分
ゴール：頭脳を本物のClaudeに戻す。ここまでの設定はすべてそのまま使えます。

切り替えを検討する目安：

こうなったら意味
「1日の上限に達しました」と出る無料枠の50回を使い切っています。実務で使えている証拠でもあります
指示と違うものが返ってくる頭脳が無料AIのためです。Claude本体なら解消する可能性が高いです
長い資料を読ませると途中で切れる無料モデルは扱える分量が小さいためです

切り替え方：

  1. claude.ai で会員登録し、Pro（月20ドル・約3,000円台）に加入
  2. 黒い画面（▶ 黒い画面の開き方はこちら）で ccr stop と打って、繋ぎ替えツールを止める
  3. 作業フォルダで claude と打つ → ブラウザが開くのでログインを許可
これだけです。STEP 1〜3・6で覚えた操作はまったく同じまま、頭脳だけが本物のClaudeに変わります。

利用可能なモデルはありません
モデル一覧が0件		正常な表示です。「＋ カスタムモデル」から nvidia/nemotron-3-ultra-550b-a55b:free を手入力し、「>」ボタンで右側へ移してください。無料モデルの顔ぶれは頻繁に入れ替わりますので、このモデルが消えていたら openrouter.ai/models で末尾が :free のものを探してください。
赤字でスクリプトの実行が無効になっているため

command not found
認識されていません		道具が入っていないか、画面を開き直していません。黒い画面を一度閉じて開き直すと直ることがほとんどです。

AIの答えがおかしい無料AIの限界です。日本語で「もっと短く」「作り直して」と伝えて再挑戦。改善しなければSTEP 7へ。
途中で完全に分からなくなったそこで止めてご連絡ください。画面を共有しながら一緒に進めます。無理に進めて設定を壊すより早く終わります。

やってはいけないこと

  • 会員様の氏名・メール・住所を入力しない。無料AIは入力内容を学習に使う場合があります。個人情報を含むデータは、正規版に切り替えるまで扱わないでください。
  • APIキー（sk-or-v1-の文字列）を人に見せない。パスワードと同じです。チャットやメールに貼らないでください。
  • 意味の分からないコマンドを、ネットからコピーして実行しない。この手順書に載っているもの以外を実行する時は、一度ご相談ください。
  • 本番のサイトが入っているフォルダで作業しない。必ず新しく作った shiryo のような空フォルダで練習してください。
